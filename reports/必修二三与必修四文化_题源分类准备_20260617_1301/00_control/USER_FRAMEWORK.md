# USER_FRAMEWORK

## 三条未来宝典线

### 必修二《经济与社会》

先按题目/小问是否考查经济制度、新发展理念、高质量发展、现代化经济体系、市场经济、宏观调控、分配与社会保障等进行归类。后续宝典生成时再按飞哥课堂框架细分。

### 必修三《政治与法治》

先按题目/小问是否考查党的领导、人民当家作主、人民代表大会制度、基层群众自治、政协协商、全过程人民民主、政府、依法治国、法治国家/法治政府/法治社会、司法等进行归类。

### 必修四《哲学与文化》文化部分

只收文化线，不收哲学线。文化线先按文化功能、中华优秀传统文化传承发展、革命文化与社会主义先进文化、文化自信、文化强国、民族精神、社会主义核心价值观、文明交流互鉴、文化遗产/非遗/文旅等进行归类。

## 边界提醒

- 出现“文化”不等于必然归文化线；如果设问或答案明确考哲学原理，归 B4_PHILOSOPHY 边界排除。
- 出现“法律/法治”不等于必修三；民事权利、合同、侵权、劳动、知识产权、诉讼程序等归 XB2 边界排除。
- 出现“思维/创新/逻辑”不等于必修三或文化；科学思维、辩证思维、创新思维、推理等归 XB3 边界排除。
- 国际关系、外交、全球治理、经济全球化等归 XB1 边界排除。
